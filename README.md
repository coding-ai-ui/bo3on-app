# بوعون — إدارة الحصص والطلاب

تطبيق Android أصلي للأستاذ بوعون وحده، باللغة العربية واتجاه RTL. يعمل محليًا دون حساب أو خادم. المادتان الثابتتان: الرياضيات والفيزياء.

## البدء

1. ثبّت ملف APK على هاتف Android 8.0 أو أحدث.
2. أضف مدرسة، ثم طالبًا. يمكن إضافة مجموعة بأيام ووقت أسبوعي وربط الطلاب بها من نموذج الطالب.
3. سجّل أول دفعة للطالب، ثم سجّل حصصه منفردة أو من الحضور.
4. عند اكتمال الاشتراك يظهر الطالب في «يجب الدفع». الدفعة التالية تبدأ عدّادًا جديدًا وتحتفظ بالتاريخ السابق.
5. احفظ نسخة احتياطية من الإعدادات قبل تغيير الجهاز أو حذف التطبيق.

لا تُضاف بيانات تجريبية إلى قاعدة بيانات الاستخدام الحقيقي. بيانات الاختبار منفصلة.

## قواعد الاشتراكات

- أربع حصص افتراضيًا. يُحفظ عدد الحصص داخل كل دفعة؛ تعديل الإعداد الافتراضي لا يغيّر الاشتراكات القديمة.
- لا تُسجّل حصة قبل أول دفعة أو بعد استهلاك الاشتراك.
- يُحسب التقدّم من الحصص المرتبطة بالدفعة الحالية، وليس بعدّاد قابل لفقدان التزامن.
- التجديد المبكر مسموح بتحذير واضح: تُحفظ الحصص غير المستهلكة في الاشتراك القديم ولا تُنقل.
- تعديل تاريخ دفعة قديمة غير متاح؛ سجل الدفعات تراكمي.
- حذف حصة يصحّح ترقيم وعدّاد اشتراكها فقط. الحضور المتكرر لا ينشئ حصصًا مكررة.
- تغيير الحضور إلى غائب أو ملغاة يلغي الحصة المرتبطة به داخل معاملة واحدة.
- حذف الطالب أو المدرسة يعني الأرشفة القابلة للاستعادة، مع حفظ التاريخ المالي. حذف المجموعة يفصل الطلاب عنها ويحفظ تاريخ حضورها.
- بداية الأسبوع يوم الأحد؛ المبالغ أعداد صحيحة بالدينار الجزائري. «المبالغ المنتظرة» تعني أسعار تجديد الاشتراكات المنتهية، وليست دينًا محاسبيًا مفروضًا.

## الأمان والنسخ الاحتياطي

- PIN اختياري من 4 إلى 8 أرقام، محفوظ باستخدام PBKDF2-HMAC-SHA256 مع salt عشوائي و120,000 دورة، وتأخير بعد المحاولات الفاشلة.
- البصمة تتطلب PIN بديلًا وبصمة قوية مسجلة في الجهاز.
- قفل عند التشغيل وبعد مغادرة التطبيق 30 ثانية؛ منع تصوير الشاشة عند تفعيل PIN.
- النسخة JSON تشمل المدارس والطلاب وصورهم والمجموعات والحضور والحصص والدفعات والملاحظات. لا تنقل PIN أو تفضيلات الجهاز أو صورة الأستاذ.
- النسخ اليدوية غير مشفرة، فاختر مكانًا آمنًا. الاستعادة تتحقق من العلاقات وسعة الاشتراكات وتستبدل البيانات في معاملة Room ذرّية.
- تصدير CSV بالعربية وUTF-8 مع معالجة الخلايا التي قد تُفسَّر كصيغ في برامج الجداول.
- لا يوجد اتصال سحابي أو إذن إنترنت للتطبيق. الاتصال وواتساب يفتحان تطبيقات الهاتف فقط.

## البناء

المتطلبات: JDK 17 أو 21، Android SDK 35، Build Tools 35.0.0. أول بناء يحتاج الإنترنت لتنزيل التبعيات؛ التطبيق نفسه يعمل دون إنترنت.

من PowerShell داخل مجلد المشروع:

للبناء بالإعدادات المحلية التي جُهزت على هذا الجهاز: `./build.ps1`. لتشغيل التحقق الكامل: `./build.ps1 -Tasks assembleDebug,testDebugUnitTest,lintDebug`.

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\openjdk\jdk-21.0.8'
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
```

يمكن أيضًا فتح المجلد مباشرة في Android Studio. يجب ضبط `local.properties` على مسار SDK المحلي؛ الملف لا يدخل في التحكم بالإصدارات.

الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

هذه نسخة تطوير موقعة بمفتاح debug. للنشر الرسمي أنشئ مفتاح إصدار خاصًا واحتفظ به خارج المستودع، ثم أضف إعداد التوقيع. لا تغيّر مفتاح التوقيع عند تحديث نسخة مستخدمة دون التخطيط لاستعادة بياناتها.

## البنية والاختبارات

Kotlin / Compose / Material 3 / Navigation Compose / Room / MVVM / Repository / StateFlow / DataStore / WorkManager / BiometricPrompt.

- `data/model`: الكيانات وقواعد تعريف البيانات.
- `data/database`: Room وعلاقات المفاتيح والفهارس.
- `data/repository`: التحقق والمعاملات والنسخ والاستعادة.
- `ui/screens`: الصفحات والنماذج العربية.
- `ui/components`: الثيم والخط المحلي والمكونات المشتركة.
- `ui/viewmodel`: حالة التطبيق وتنفيذ العمليات والأخطاء.
- `utils`: التنسيق والصور والتذكيرات.
- `app/src/test`: اختبارات قاعدة البيانات والاشتراكات والحضور والتنقل والواجهات عبر Robolectric.

مخطط Room الأول محفوظ في `app/schemas`. لا توجد destructive migrations. عند تغيير المخطط لاحقًا ارفع رقم الإصدار وأضف `Migration` صريحة واختبار ترحيل من المخطط السابق قبل الإصدار.

تظهر تقارير الاختبارات في `app/build/reports/tests/testDebugUnitTest`، وصور الواجهات في `app/build/reports/screenshots`.

## ملاحظات تشغيل

- تذكيرات WorkManager غير دقيقة بالثانية؛ يحدد Android موعد تشغيلها، وقد يؤخرها وضع توفير الطاقة. يحتاج Android 13+ إذن الإشعارات.
- المجموعات أسبوعية متكررة. للغياب أو إلغاء حصة اختر الحالة في صفحة اليوم؛ التاريخ السابق متاح من منتقي التاريخ.
- الصور مضمنة محليًا بدقة مصغرة لتعمل دون اتصال وتنتقل مع النسخ الاحتياطية.
- الخط Tajawal مرخّص بموجب SIL Open Font License، راجع `FONT-LICENSE.txt`.
